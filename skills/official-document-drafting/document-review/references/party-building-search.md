# 党建权威平台检索策略

## 可用平台

学习强国和灯塔-党建在线没有公开 API，Tavily 也无法有效搜索。用以下等效权威平台替代：

| 平台 | 网址 | Tavily 搜索效果 | 特点 |
|------|------|:---:|------|
| 共产党员网 | 12371.cn | ✅ 好 | 中组部主管，全国党员教育平台 |
| 党建网 | dangjian.cn | ✅ 很好 | 中宣部主管，当天文章可搜到 |
| 人民网党建频道 | dangjian.people.com.cn | ⚠️ 一般 | 人民日报旗下，时效性略差 |
| 求是网 | qstheory.cn | 待验证 | 《求是》杂志官网 |

## 检索方法

### 站点限定语法

```
site:12371.cn {关键词}
site:dangjian.cn {关键词}
```

### 多轮递进式检索

**第 1 轮：宽泛检索**
- 目的：获取该主题方向的最新权威论述
- 示例：`site:dangjian.cn 全面从严治党 最新`
- 每个方向搜 2 个平台，每个平台取 Top 3

**第 2 轮：精准检索**
- 目的：验证文中引用的具体文件、会议、讲话
- 示例：`site:12371.cn 全国党建工作座谈会 2026`
- 针对文档中出现的每一个引用来源逐一检索

**第 3 轮：深挖疑点**
- 目的：当 LLM 怀疑某个提法可能过时时，进一步验证
- 示例：搜索该提法 + 最新年份，查看是否仍在现行文件中使用

### 去重与排序

```python
# 多平台结果合并去重（按 URL）
seen = set()
unique = [r for r in all_results if r['url'] not in seen and not seen.add(r['url'])]

# 按日期降序，取 Top 10
unique.sort(key=lambda r: r.get('date', ''), reverse=True)
top_10 = unique[:10]
```

### 全文提取

对 Top 10 结果调用 `web_extract` 提取全文，每篇限制 5000 字符，作为 LLM 审核的参考依据。

## 时效性处理

- 优先采用近 6 个月内的文件作为参考
- 超过 1 年的参考文件降低权重，标注"时效性可能不足"
- 如果某表述在多个近期的权威来源中均出现，视为"当前标准提法"

## 学习强国和灯塔的说明

当需要向用户解释为何不使用学习强国/灯塔时，措辞建议：
"学习强国和灯塔-党建在线目前没有对外提供内容数据接口，方案中以共产党员网（中组部主管）和党建网（中宣部主管）作为等效权威来源，两者在权威性和时效性上可以满足审核需求。"
